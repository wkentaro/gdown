========Экспертное мнение========
Обнаружено 4 уязвимости высокого уровня с тестом B202 в файле ./gdown/extractall.py.
Функция tarfile.extractall() используется без параметра filter или с непроверенными members. 
Это означает, что при распаковке tar-архива имена файлов внутри архива не валидируются.
Злоумышленник может создать архив с именами вида ../../etc/passwd,и при распаковке файл будет записан за пределами целевой директории.
 Что опасно для пользователя, который использует данную библиотеку
Если пользователь запустит gdown с sudo — последствия опасны для системы(запись в /etc, /usr, /root).
========Рекомендации:========
Для python3.12+: Использовать функцию .extracall() c аргументом filter="data"
Для старых версий Python: Использовать проверку, что итоговый путь остаётся внутри целевой директории
